# Auditoría SII · corte del 8 de noviembre de 2026

FELINE presenta brechas que impiden acreditar cumplimiento total. La API persistente admite 33, 34, 39, 41, 56 y 61. El alcance de emisión probado difiere por tipo. No se constató evidencia oficial de certificación o autorización. Los tipos 43, 46, 52, 110, 111 y 112 carecen de entrada por la API v1.

Se detectó un FRMA inválido en un CAF sintético. Tras corregir el generador de prueba, los sobres nuevos 33 y 39 pasaron sus XSD oficiales. La firma de un CAF real, el envío autorizado, las reglas tributarias por operación y el ciclo financiero requieren evidencia adicional. Consultar la matriz para el detalle de este corte.
