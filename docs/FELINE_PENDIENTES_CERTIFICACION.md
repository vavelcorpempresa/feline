# Pendientes de certificación

1. Conseguir acceso autorizado, certificado de prueba, CAF válidos y set asignado para el emisor.
2. Validar cada tipo con campos condicionales, XSD, firma, TED y PDF417. Registrar muestras, huellas y resultados.
3. Verificar transporte oficial por ambiente, respuesta, reparos, rechazo y reintentos.
4. Completar ILA persistente, recepción, intercambio, entrega, registros y requisitos específicos de boletas.
5. Completar las etapas oficiales y conservar la autorización del SII antes de habilitar operación productiva.
